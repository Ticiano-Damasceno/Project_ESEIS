# Formato

```dd.mm.aaaa tipo(escopo): descrição curta```

## Exemplos

```20.03.2020 feat(auth): adiciona login com JWT```
```20.03.2020 fix(agenda): corrige conflito de reserva```
```20.03.2020 refactor(api): reorganiza serviços de usuários```
```20.03.2020 docs(readme): atualiza instruções do projeto```
```20.03.2020 test(financeiro): adiciona testes de multa```
```20.03.2020 chore(build): ajusta configuração do projeto```

## Tipos mais usados
`feat` → nova funcionalidade
`fix` → correção de bug
`refactor` → refatoração sem mudar regra
`docs` → documentação
`test` → testes
`chore` → tarefas de manutenção
`style` → ajustes visuais/formatos
`perf` → melhoria de performance
